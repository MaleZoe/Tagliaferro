# Plantillas de encuesta

Estas plantillas están listas para aplicar. Registrar respuestas reales con consentimiento y sin cargar datos personales innecesarios; no se incluyen participantes ni resultados inventados.

## Clientes

1. ¿Cómo encontrás los productos por deporte, talle y precio?
2. ¿Qué información necesitás ver antes de comprar?
3. ¿En qué paso del carrito o pago tuviste dudas?
4. ¿Cómo preferís consultar el estado de un pedido?
5. ¿Qué mejorarías en la tienda?

## Empleados

1. ¿Cómo registrás actualmente una entrada, salida o ajuste de stock?
2. ¿Qué errores ocurren al identificar productos y talles?
3. ¿Qué datos necesitás durante una venta presencial?
4. ¿Cómo recibís y reportás tareas internas?
5. ¿Qué alertas ayudarían a evitar faltantes?

## Administración

1. ¿Qué indicadores necesitás revisar por día o período?
2. ¿Cómo se autorizan actualmente cambios de precio, stock y permisos?
3. ¿Qué trazabilidad necesitás para una anulación o devolución?
4. ¿Cómo se priorizan proyectos y tareas internas?
5. ¿Qué reportes son necesarios para tomar decisiones?
